# Quarantined Legacy Audits, Builders, and Payloads

Nothing in this directory may be read by an active script, figure generator, or Kaggle
notebook. `tools/verify_all_integrity.py` fails if any active file references a name
listed here. The canonical sources are `scripts/run_verified_experiments.py` →
`research/verified_json/*.json`, and the only gate is `scripts/reproduce_all.py`.

## `*.py` / `*.json` at this level — calibrated audits

| file | why quarantined |
|---|---|
| `build_regime_a_per_task.py` | assigned per-task Regime A outcomes synthetically; no per-task series was ever measured |
| `regime_a_per_task.json` | output of the above, so it cannot support per-task claims |
| `symrank_v6.py` | hardcoded calibration loop plus a fallback query parser; the `37/121 → 49/121` line is not reproducible |
| `symrank_v6_results.json` | output of the above |
| `statistical_rigor_audit.py` | simulated paired loops and non-standard subset denominators (125/122/121) |
| `statistical_rigor_results.json` | output of the above; its summary (21/27) disagrees with its own per-task records (22/28) |

## `retired_builders/` — generators that would overwrite corrected artifacts

| file | why quarantined |
|---|---|
| `build_master_writeup.py` | writes `docs/MASTER_WRITEUP_FINAL.md` with hardcoded `+30.92 pp`, `38/121`, `44/121`, `symrank_v6`, and the 8.5% `.gitignore` claim. Running it silently reverts the corrected paper. |
| `build_noise_notebook.py` | rebuilds the public `g4-paper-noise-mde` kernel from `results/claim*.json`, i.e. from the retracted payloads. |
| `build_resource_notebook.py` | rebuilds the public `g4-paper-graph-benchmark` kernel from the same generation. |

Replaced by `tools/build_paper_notebooks.py`, which embeds `research/verified_json/*.json`
and asserts internal consistency at run time. The two replacement notebooks are
`g4-paper-graph-benchmark` and `g4-paper-noise-mde`.

## Quarantine policy

1. No active file may reference a quarantined name; `tools/verify_all_integrity.py`
   enforces this by scanning every `.py` and `.ipynb` outside this directory.
2. A number that cannot be regenerated by `scripts/run_verified_experiments.py` does not
   appear in any deliverable.
3. Restoring a file from here requires re-deriving its numbers from a deterministic
   producer and adding them to `scripts/reproduce_all.py`.
