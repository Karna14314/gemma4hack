# swe_toolkit
Run `python skills/swe_toolkit/scripts/swe.py locate --query "..."` to get top files/symbols.
Run `inspect --symbol <name>` for callers/twins.
Run `verify [--test "..."]` for syntax/patch/JUnit gate.
State cached in /tmp/swe_state.json.
